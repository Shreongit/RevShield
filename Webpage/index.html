Context & Challenge

The web is more complex than it looks.

When you navigate to a standard webpage, dozens of unseen background connections trigger automatically. Understanding their privacy and security implications is rarely straightforward.

Hidden Third-Party Requests

Modern websites frequently bundle scripts from 10 to 50+ third-party domains, including behavioral analytics, tag managers, and session replay recorders that monitor user interactions.

Advertising & Retargeting Networks

Programmatic ad exchanges synchronize identifiers across visits, building detailed behavioral profiles across unrelated web properties without transparent user awareness.

Opaque Security Configurations

Missing security headers (HSTS, CSP, X-Frame-Options), weak TLS cipher suites, and unflagged persistent cookies leave web applications vulnerable to clickjacking, MITM, and credential interception.

Core Capabilities

What REVSHIELD Analyzes

A multi-engine audit suite breaking down transport security, privacy posture, cookies, and machine learning threat vectors into transparent findings.

Security & Transport

Deep socket-level certificate verification and defensive HTTP response header audit.

  • TLS 1.2 & 1.3 handshake verification
  • Certificate issuer, SAN, & expiration check
  • CSP, HSTS, X-Frame-Options & Referrer Policy
  • Protocol downgrade detection (HTTPS → HTTP)

Privacy & Trackers

Categorization of tracking beacons, analytics suites, and telemetry collectors.

  • Web traffic telemetry & analytics (GA, Segment)
  • Session recording & heatmaps (Hotjar, Clarity)
  • Social conversion pixels (Meta, TikTok, LinkedIn)
  • Canvas and audio fingerprinting vectors

Advertising Networks

Inspection of programmatic ad distribution, exchanges, and retargeting scripts.

  • DoubleClick & Google Syndication ads
  • Behavioral retargeting engines (Criteo, Taboola)
  • Real-time bidding & supply-side exchanges
  • Sponsored content injection hooks

Cookies & Storage

Scope, persistence, and security flag validation without exposing sensitive token contents.

  • First-party vs. third-party cookie isolation
  • Secure, HttpOnly, and SameSite attribute check
  • Persistent vs. session expiration duration
  • Zero credential logging guarantee

Threat & Phishing ML

Interpretable machine learning classification examining 25+ structural and lexical features.

  • Punycode / IDN homograph attack detection
  • Shannon entropy domain randomness scoring
  • Excessive subdomain depth & keyword heuristics
  • Calibrated probability with feature factor breakdown

Transparent Scoring

Deterministic 0-100 composite index where every point deduction is explicitly explained.

  • Weighted security, privacy, and threat factors
  • Graded risk tiers: Safe, Low, Suspicious, High
  • Positive bonus credits for best practices
  • Prioritized remediation advice
Analysis Lifecycle

How It Works

From target URL input to structured findings report, every stage is designed for isolation, security, and transparent factor computation.

STEP 01

URL Ingestion

The target URL is normalized, stripping tracking query parameters, fragments, and standardizing protocol schemes.

STEP 02

Anti-SSRF Validation

DNS is pre-resolved. Private subnets (RFC 1918), loopback (127.0.0.1, ::1), and cloud metadata IPs are strictly rejected.

STEP 03

Multi-Vector Audit

Analyzers inspect TLS handshakes, HTTP security headers, third-party network scripts, cookies, and run ML phishing inference.

STEP 04

Score & Intelligence

Findings are compiled into sub-scores, transparent factor breakdowns, and remediation steps with JSON export.

Manifest V3 Extension

Protection that continues while you browse.

While the web application analyzes individual websites on demand, the REVSHIELD browser extension delivers continuous, zero-latency local protection directly inside Chromium browsers.

Local DNR Execution

Blocking happens inside Chromium's DeclarativeNetRequest network engine before tracking scripts execute.

Real-Time Stats

Maintains distinct counters for blocked ads and blocked trackers for both the current website and lifetime browsing.

Per-Site Whitelisting

Easily pause protection for specific trusted domains with a single toggle directly from the popup.

Zero History Streaming

Your personal browsing history, visited URLs, and cookies are never transmitted to any remote server.

Design Principles

Protection should not require surveillance.

Security and privacy tools must uphold the highest standards of data minimization. REVSHIELD operates on a strict local-first model.

100% LOCAL OPERATION

Browser Extension

DeclarativeNetRequest rules compile into Chromium's native network layer. Network request blocking, category counting, and whitelist decisions occur locally on your machine.

  • No URL streaming to external backends
  • No tracking of visited browser history
  • No capture of form inputs or credentials

Value Proposition

Why REVSHIELD

Built from the ground up for transparency, auditability, speed, and uncompromising user privacy.

Understand Websites Better

Gain immediate visibility into what third-party vendors and tracking scripts load when you visit any website. Discover missing security headers and inspect TLS certificates with clear educational advice.

Local-First Protection

Supported ads and trackers are blocked directly in your browser using native DeclarativeNetRequest rules with zero performance overhead.

100% Free & Open Source

Every line of code is open under the MIT license. No hidden analytics, no premium paywalls, and no account requirements.

Transparent Deterministic Scoring

Unlike black-box security tools, REVSHIELD calculates risk scores using transparent, documented factors with explicit positive and negative point explanations.

Honesty & Scope

Transparent by design.

Security and privacy tools must be honest about their boundaries and technical realities.

REVSHIELD is designed to assist in auditing, threat detection, and continuous ad/tracker blocking. However, no automated software can guarantee 100% safety across the ever-changing web:

Dynamic Evasion Techniques

Novel tracker domains, CNAME cloaking, and first-party proxy routing may occasionally bypass static signature rules until signatures are updated.

ML Classifier Boundary

Machine learning phishing classification is heuristic-assisted and may occasionally produce false positives or false negatives on highly novel URL patterns.

Browser API Sandbox

Manifest V3 DeclarativeNetRequest operates within strict browser rule quotas and cannot modify websocket payloads or dynamic memory directly.

No Safety Guarantee

A high score indicates good defensive configuration and low tracker presence; it does not replace comprehensive enterprise penetration testing.

Open Source Community

Built to be inspected.

REVSHIELD is distributed under the MIT Open Source License. You can freely inspect the code, audit the algorithms, contribute tracker signatures, or self-host your own instance.

Developer Guide

Run REVSHIELD Locally

Follow these steps to clone the repository and launch the FastAPI backend, React web application, and browser extension on your local machine.

STEP 1

Clone the Repository

git clone https://github.com/ifshreyas/RevShield.git
cd RevShield
STEP 2

Start the Backend Analysis Engine (FastAPI)

cd apps/api
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

→ Swagger documentation will be available at http://localhost:8000/docs

STEP 3

Start the Web Application (React + Vite)

# From project root
npm install
npm run dev:web

→ Web application will be available at http://localhost:5173

STEP 4

Build & Load the Browser Extension

npm run build:extension

Load into Chrome, Brave, Edge, or Arc:

  1. Navigate to chrome://extensions
  2. Enable Developer mode (top-right toggle)
  3. Click Load unpacked and select RevShield/apps/extension/dist
ALTERNATIVE

Full-Stack Deployment with Docker Compose

docker-compose up --build
